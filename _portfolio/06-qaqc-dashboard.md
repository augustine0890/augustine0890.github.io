**Company:** FPT Software Korea · **Role:** Data Software Engineer

A data processing and reporting system that aggregates QA/QC records and delivers statistical quality insights through APIs and dashboards.

### Key Contributions

- Built **SQL and Java pipelines** to aggregate, preprocess, and analyze large QA/QC datasets.
- Used **Apache Commons Math** for statistical analysis of trends and anomalies.
- Developed **Spring Boot REST APIs** and **Chart.js dashboards** to deliver real-time statistical reports to stakeholders.

### Tech Stack

`SQL` · `Java` · `Oracle` · `Apache Commons Math` · `Chart.js` · `REST APIs` · `Spring Boot`
